# ESPEAK — План интеграции рекламы (черновик)

> Сохранено: 2026-05-12. Идея на будущее — НЕ реализуется сейчас.
> Связано с `MONETIZATION_PLAN.md` (Premium как «Remove ads» upsell).

---

## Главное решение

**Не торопиться с рекламой.** Порог входа:
- DAU стабильно ≥ 3000
- Retention D7 ≥ 30%
- Подписка Premium уже запущена и работает

**До этого реклама заработает меньше чем испортит UX.**

---

## Типы рекламы и их экономика

### 1. Interstitial (полноэкранная)
- **Когда**: между сессиями, после завершения урока
- **Длительность**: 5-30 сек, скип через 5 сек
- **Доход**: $1-3 за 1000 показов в РФ, $5-15 в US/EU
- **Применение**: используется в Duolingo, Busuu

### 2. Rewarded (награждаемая) ⭐ ЛУЧШИЙ ДЛЯ НАС
- **Когда**: юзер сам соглашается за бонус
  - «+50 XP за просмотр»
  - «Подсказка в игре за просмотр»
  - «+1 жизнь / попытка»
- **Длительность**: 15-30 сек, нельзя пропустить
- **Доход**: $5-15 за 1000 показов в РФ — **самый дорогой формат**
- **Плюс**: не злит юзера, воспринимается как бонус

### 3. Banner (баннер внизу)
- **Доход**: $0.20-0.80 за 1000 показов — гроши
- **Минус**: визуально дешевит, занимает 50dp
- **Решение**: НЕ ИСПОЛЬЗОВАТЬ

### 4. Native
- В обучающих почти не встречается. Пропускаем.

## Реальные цифры дохода

На 10 000 DAU в РФ:

| Формат | Показов/день | Месячный доход |
|---|---|---|
| Interstitial 3/день | 900k | $900-2700 (~70-200 тыс ₽) |
| Rewarded 1/день | 300k | $1500-4500 (~115-340 тыс ₽) |
| Баннер постоянный | 1.5M | $300-1200 (~23-90 тыс ₽) |

**Итого с 10к DAU: 200-600 тыс ₽/мес**

**Сравнение с подпиской**: 10к DAU × 3% конверсии × 250 ₽ = **750 тыс ₽/мес**.
Подписка выгоднее рекламы в 3-5 раз при тех же юзерах.

**При DAU < 1000 реклама бессмысленна** — заработаешь <10к ₽/мес, ухудшишь UX.
**Точка окупаемости труда: ~3-5к DAU.**

## Российский рынок — отдельная история

После 2022:

| Сеть | Статус | Выплаты |
|---|---|---|
| **Google AdMob** | Работает, нужен mediation | Международный счёт (Казахстан/Армения/Грузия для ИП РФ) |
| **Yandex.Advertising Network** | Работает | В рублях, на российский ИП |
| **Unity Ads / IronSource / Mintegral** | Работает | Через зарубежные счета |
| **Meta Audience Network** | Работает | Зарубежные счета |

**Mediation** (несколько сетей одновременно) поднимает fill rate на 30-50% — обязательно для серьёзного дохода.

Что выбирать:
- Деньги в РФ → **Yandex** как основа + AdMob как fallback
- Деньги через зарубеж → **AdMob + mediation** (выгоднее по CPM)

## "Remove ads" как upsell

Это **самая сильная конверсионная воронка** в обучающих приложениях.

Стандартная схема (Duolingo, Babbel, Lingvist):
```
Бесплатно → реклама после каждого урока
    ↓
"Достал баннер? — отключи за 199 ₽/мес"
    ↓
Premium = (рекламы нет) + (контент A2+)
```

**~30% Premium-конверсий у Duolingo идёт через «не могу больше смотреть рекламу».**

В нашей модели Premium = (A2+ контент + тренажёр + AI безлимит).
Если добавить **(отсутствие рекламы)** — конверсия вырастет дополнительно на 20-40%.

## Технический план реализации (1-2 дня работы)

Когда придёт время:

### Этап 1: SDK
- `com.google.android.gms:play-services-ads:latest` (AdMob)
- Опционально: `com.yandex.android:mobileads` (Yandex для РФ-выплат)
- AdMob mediation с 2-3 сетями: Meta, Unity, IronSource

### Этап 2: Точки показа

**Interstitial** — редко, чтобы не злить:
- После завершения урока: 1 раз из 3 завершений (не каждый раз)
- Frequency cap: максимум 1 interstitial за 5 минут (иначе бан в Play)

**Rewarded** — там где юзер сам захочет:
- `PracticeScreen` / `FlashcardsScreen`: «Получи +25 XP» при низкой серии
- Игры: «Купи подсказку за просмотр» — особенно в Crucigrama, Anagram, Palabra Maestra
- LessonSession: «Дополнительная попытка» при провале (опционально)

**НЕТ**:
- ❌ Никаких баннеров
- ❌ Никакой рекламы в Dictionary (handbook-функция)
- ❌ Никакой рекламы в AI-чате (странно вклинивается)

### Этап 3: Premium-gate
```kotlin
fun showAd(activity: Activity, onComplete: () -> Unit) {
    if (premiumGate.isPremium()) {
        onComplete()  // Premium-юзеру никогда не показываем
        return
    }
    // Показ рекламы → onComplete после закрытия
}
```

### Этап 4: GDPR/Consent
- **Обязательно** на территории РФ/ЕС
- SDK: `com.google.android.ump:user-messaging-platform`
- Consent dialog при первом запуске
- Иначе бан в Play Console

### Этап 5: Тестирование
- Test ad units на dev-сборке (НЕ продакшен ID)
- Проверить frequency capping
- Проверить что Premium-юзер не видит рекламу
- Проверить consent flow на чистой установке

## Resume этой темы

Когда вернёмся к рекламе:

1. Проверить условия запуска:
   - DAU ≥ 3000?
   - D7 retention ≥ 30%?
   - Premium-подписка работает 1-2 месяца?
2. Если ДА — реализовать **только rewarded в играх** для начала (1 день работы)
3. Через 1 месяц анализировать impact на retention
4. Если retention не упал — добавить interstitial после уроков (frequency 1 из 3)
5. Параллельно — «Remove ads» в Premium UI как новый аргумент к подписке

**Никогда** не добавлять баннеры. **Никогда** не ставить interstitial на каждом завершении урока — это убьёт UX и retention.
