🏁 Чекпоинты ESPEAK

16 уникальных финальных экзаменов · 4 модуля × 4 блока

Концепция: каждый блок курса завершается чекпоинтом — story-driven мини-сценой с NPC. Юзер играет роль (Andrea, с подменой страны по геолокации), общается с персонажем используя ТОЛЬКО материал текущего блока. Pass — открывается следующий блок. Fail — задержка, повтор уроков. Каждые 4 чекпоинта = финал модуля (BOSS со смешанным контентом).
Прогресс мокапов Все 16 HTML мокапов готовы. Module 1 (A1) уже в коде Android — можно играть. Module 2-4 — мокапы как design spec, контент уроков для них будет создан после релиза A1.
