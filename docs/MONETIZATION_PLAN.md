# ESPEAK — План монетизации (черновик)

> Сохранено: 2026-05-12. Решение по итогу обсуждения с владельцем.
> Это **идея на будущее** — не реализуется прямо сейчас, вернёмся позже.

## Финальная freemium-модель

### 🆓 Бесплатно
- **Словарь полностью** — слова + фразы + произношение + примеры (handbook-функция, не должна быть платной)
- **Уроки A1** — 60 микро-уроков, 4 блока («Взлёт», «Мой мир», «Действие», «Выживание»)
- **Книги A1** — ~25 рассказов с квизом и переводом по long-press
- **Карточки A1** — SM-2, тематические наборы
- **7 игр**: Crucigrama, Articulos, Math, Speed, Anagram, Palabra Maestra, Sopa
- **Геймификация**: Streak / XP / Лиги / Ачивки / Weekly leagues
- **AI-чат** с лимитом 10-20 сообщений/день
- **Произношение** (Pronunciation Screen)

### 💎 Платно (Premium)
- **Уроки A2 / B1 / B2** — ~180 уроков (грамматика + лексика + упражнения)
- **Книги A2+** — ~75 рассказов
- **Карточки A2+** — SM-2 с расширенным словарём
- **Тренажёр глаголов** — 1251 verb × 5 тиров × 6 времён
- **AI-чат безлимит** + ролевые сценарии (доктор, отель, бизнес)

### Логика для пользователя
> «Бесплатно — учиться с нуля до A1 + всегда смотреть слова.
>  Платно — расти выше.»

## Ценообразование (рекомендация)

Реалистичный диапазон при текущем качестве контента:

- **199-299 руб/мес** — месячная подписка
- **1490-1990 руб/год** — годовая (~6 месяцев бесплатно)
- **Lifetime 3990-4990 руб** — для тех кто не любит подписки (российский рынок такое любит)

Сравнение с рынком:
| Конкурент | Цена | Что даёт |
|---|---|---|
| Duolingo Super | 599 руб/мес | Без рекламы, без сердечек |
| Babbel | ~1300 руб/мес | Глубокий контент A1-B2 |
| Busuu | ~800 руб/мес | Native speaker review |
| LingQ | ~1100 руб/мес | Лучшее для чтения |

**Не ставить 500+** на текущем контенте — Babbel за эти деньги даёт больше глубины.

## Технический план реализации (3-5 дней работы)

### День 1: BillingClient интеграция
- Добавить `com.android.billingclient:billing-ktx:latest` в `app/build.gradle.kts`
- Создать SKU в Google Play Console:
  - `espeak_premium_monthly` (subscription)
  - `espeak_premium_yearly` (subscription)
  - `espeak_premium_lifetime` (one-time, опционально)
- `data/prefs/PremiumPreferences.kt` — DataStore флаг `isPremium` + срок истечения
- `service/BillingManager.kt` — подключение Play Billing, обработка покупок, restore

### День 2: Paywall-экран
- `ui/premium/PaywallScreen.kt` — Compose-экран с:
  - Showcase платных фич (картинки + описания)
  - 3 кнопки: monthly / yearly (best value badge) / lifetime
  - «Попробовать 7 дней бесплатно» (главная CTA)
  - Кнопка «Restore purchases»
  - Ссылки на Privacy Policy и Terms
- Маршрут в `Navigation.kt`: `premium`

### День 3: Гейтинг точек
- `domain/premium/PremiumGate.kt` — единый объект `isPremiumOrTrial()`
- Применить в:
  - `LevelSelectionScreen` — серые карточки + замок для A2/B1/B2
  - `CourseDetailScreen` — early return на премиум-роут
  - `LibrosScreen` — фильтрация списка
  - `GamesScreen` — карточка тренажёра
  - `AiChatViewModel` — счётчик сообщений за день, после лимита эмитим event «requirePremium»

### День 4-5: Trial + edge cases
- Trial логика — 7 дней без карты через локальный таймер ИЛИ Play `freeTrialPeriod` в SKU
- Восстановление покупок — кнопка в Settings + автопроверка при старте
- Edge cases:
  - Отмена подписки → grace period 3 дня → перевод в free
  - Refund → немедленный downgrade
  - Истечение trial → soft paywall с «Продолжить за X руб/мес»
  - Cross-device — синк через Firebase (user uid → premium status)

## ⚠️ Что должно быть готово ДО запуска paywall

Иначе будут возвраты и 1-2★ отзывы:

1. **Чёткий paywall UI** — никаких неожиданных блоков посреди урока
2. **Базовая адаптивная коррекция** — 5-7 концепт-тэгов (ser_estar, por_para, indefinido_vs_perfecto, subjuntivo_dudo, gender_agreement) с отдельным трекингом точности. Когда падает <50% — генерим серию упражнений на этот концепт. **Самая ощутимая премиум-фича**
3. **Объяснения ошибок** для платных уроков — хотя бы 50-100 авторских объяснений в самых типовых случаях
4. **Trial-период 7 дней** — иначе конверсия будет 1-2%, не 8-10%

### Можно отложить (фичи-приятности, не блокеры):
5. Концепт-граф с prerequisites
6. Castellano vs LatAm развязка
7. Связное аудирование (длинные диалоги)
