# ESPEAK — Поддержка проекта (донаты)

> Сохранено: 2026-05-12. Идея на будущее — НЕ реализуется сейчас.
> Решение владельца: внешние агрегаторы, никакого Play Billing для донатов.

---

## Главное решение

**Отдельный пункт в Settings** → ведёт на внешние платформы для донатов.
Минимальная сумма $1 / 100 ₽. Сумма свободная.

**Никакого Google Play Billing** — это упрощает всё:
- Нет 30% комиссии Play
- Нет ограничений Google по «donations only for nonprofits»
- Нет SKU и тестирования биллинга
- Деньги напрямую владельцу через выбранную платформу

---

## Платформы — рекомендация

| Платформа | Аудитория | Комиссия | Выплаты |
|---|---|---|---|
| **Boosty** ⭐ | РФ + СНГ | ~5-10% | На карту РФ, рубли |
| **Patreon** | Зарубеж | ~8-12% | Международный счёт |
| **Buy Me a Coffee** | Зарубеж | ~5% | PayPal/Stripe |
| **DonationAlerts** | СНГ | ~5% | Карта РФ |
| **ЮKassa** (для ИП) | РФ | 2-3.5% | На счёт ИП РФ |

**Минимальный набор для запуска:**
- **Boosty** — основной канал для русскоязычной аудитории
- **Buy Me a Coffee** — для тех кто за рубежом или хочет крипту

Опционально: добавить ЮKassa если у владельца есть ИП и хочется минимальную комиссию.

## Технический план реализации (1-2 часа работы)

Когда придёт время — это самая лёгкая фича из всех планируемых.

### 1. Один Composable экран
`ui/donations/DonationsScreen.kt`:

```kotlin
@Composable
fun DonationsScreen(navController: NavHostController) {
    val context = LocalContext.current
    val uriHandler = LocalUriHandler.current

    Scaffold(
        topBar = { TopAppBar(...) }
    ) { padding ->
        Column(...) {
            Text("Описание проекта...")

            Button(onClick = {
                uriHandler.openUri("https://boosty.to/espeak")
            }) {
                Text("❤️ Boosty (для России)")
            }

            Button(onClick = {
                uriHandler.openUri("https://buymeacoffee.com/espeak")
            }) {
                Text("☕ Buy Me a Coffee")
            }
        }
    }
}
```

### 2. Маршрут в Navigation.kt
```kotlin
composable("donations") { DonationsScreen(navController) }
```

### 3. Пункт в SettingsScreen
В существующем `SettingsScreen.kt` добавить рядом с другими пунктами:
```kotlin
SettingsItem(
    icon = Icons.Default.Favorite,
    label = stringResource(R.string.settings_support_project),
    iconTint = Color(0xFFE91E63)  // розовый акцент
) {
    navController.navigate("donations")
}
```

### 4. Локализация
`res/values/strings.xml` (+ uk/es/en):
```xml
<string name="settings_support_project">Поддержать проект</string>
<string name="don_title">Поддержать проект</string>
<string name="don_intro">ESPEAK — независимый проект. Ваша поддержка помогает...</string>
<string name="don_min_amount">Минимальная сумма: 100 ₽ ($1)</string>

```

### 5. Strings — реальные URL
В `strings.xml` отдельные ключи для URL чтобы можно было менять без перекомпиляции:
```xml
<string name="boosty_url" translatable="false">https://boosty.to/espeak</string>
<string name="bmc_url" translatable="false">https://buymeacoffee.com/espeak</string>
```

## Что нужно от владельца

До реализации технической части:

1. **Создать аккаунт на Boosty** — `boosty.to/espeak` (или другой удобный handle)
   - Привязать карту для выплат
   - Настроить уровни поддержки (опционально — Boosty это позволяет)
   - Заполнить страницу: описание проекта, что финансируется

2. **Создать аккаунт на Buy Me a Coffee** — `buymeacoffee.com/espeak`
   - Привязать PayPal или Stripe
   - Заполнить профиль на английском

3. **Опционально**: открыть ИП РФ + подключить ЮKassa для минимальной комиссии (2-3.5%)

4. **Написать тексты для страниц** — короткое описание зачем донат, на что идут деньги

## Бейдж «Supporter» в профиле (опционально)

Если хочется наградить тех кто задонатил — есть тонкий путь:

- **Promocode flow**: после доната Boosty присылает донатеру промокод
- В приложении в Settings → «У меня есть промокод» → ввод → активация бейджа в профиле
- Бейдж — **только визуальный**, не даёт привилегий (иначе нарушение Play)
- Хранить: `UserProgressEntity.supporterCode: String?`

Это **дополнительная ручная работа** (генерация и рассылка кодов), оправдано только если донатов будет много.

**Альтернатива проще**: на странице Boosty написать «Спасибо за поддержку! Напиши на support@espeak.app — мы выдадим бейдж в приложении». Полу-ручной флоу, но работает.

## Прогноз дохода

Реалистичные цифры для русскоязычной аудитории:

| DAU | Конверсия в донат | Средний чек | Месяц |
|---|---|---|---|
| 500 | 0.2% (1 чел/мес) | 300 ₽ | 300 ₽ |
| 2 000 | 0.5% (10 чел/мес) | 350 ₽ | 3 500 ₽ |
| 10 000 | 0.8% (80 чел/мес) | 400 ₽ | 32 000 ₽ |
| 50 000 | 1.0% (500 чел/мес) | 450 ₽ | 225 000 ₽ |

**Донаты — побочный канал**, не основной. Конверсия очень низкая (0.2-1%) даже у популярных проектов.
**Реальная ценность**: лояльность аудитории + сигнал «продукт ценен», а не деньги сами по себе.
