# Мой словарный запас — design doc

> Статус: **🧊 ОТЛОЖЕНО** (план сохранён 2026-05-29, реализация не начата)
> Решение: юзер одобрил концепт, попросил сохранить и не делать пока.

## Идея

Превратить разрозненные сигналы обучения (уроки / SM-2 / чат / игры /
произношение / Libros) в единое представление **личного словарного
запаса** юзера. Дать ему конкретное число "ты знаешь X слов" вместо
абстрактного XP.

## Источники сигнала (уже есть в проекте)

| Источник | Что говорит | Таблица |
|---|---|---|
| Уроки | юзер встретил слово | `lesson_progress` |
| Флэшкарты SM-2 | EF / interval / repetitions — как твёрдо помнит | `word_progress` |
| Чат AI (отправленные сообщения) | юзер сам **использовал** слово | `user_word_freq` DataStore |
| Чат AI corrections | модель поправила → юзер ошибся | corrections_json в `chat_messages` |
| Игры | правильно/неправильно по слову | `game_level_progress` |
| Произношение | пытался озвучить | через STT |
| Libros (чтение) | пассивная экспозиция | `libro_progress` |
| Конъюгация | спрягал глагол | в `word_progress` |
| Поиск в словаре | смотрел значение | `recent_searches` |

## Модель данных

```kotlin
@Entity(tableName = "user_vocab_state")
data class UserVocabState(
    @PrimaryKey val word: String,         // "hola"
    val cefr: String?,                    // "A1" / "A2" / "B1" / "B2"
    val status: String,                   // VocabStatus enum
    val score: Float,                     // 0.0 — 1.0 итоговый
    val lessonSeen: Boolean,              // встретил в уроке?
    val flashcardEf: Float,               // SM-2 EF (1.3 — 2.5)
    val usageCount: Int,                  // сколько раз сам написал в чате
    val correctionsCount: Int,            // сколько раз AI поправил
    val lastSeenAt: Long,                 // когда последний раз использовал
    val productionsCount: Int,            // active (написал)
    val recognitionsCount: Int,           // passive (прочитал в Libros)
    val updatedAt: Long,                  // когда последняя агрегация
)

enum class VocabStatus {
    UNKNOWN,    // ⚪ никогда не встречал
    SEEN,       // 👁 видел в уроке, не закреплено
    LEARNING,   // 📚 в SM-2 пуле, EF растёт
    PRODUCING,  // ✍️ использует сам в чате
    MASTERED,   // ⭐ EF≥2.5 + использовал ≥10 раз
}
```

## Алгоритм агрегации

Простая взвешенная формула (можно тюнить):

```
score = 0.35 * (SM2_EF / 2.5).coerceIn(0,1)        // как твёрдо помнит
      + 0.25 * tanh(usageCount / 5)                // как активно использует
      + 0.20 * tanh(lessonExposure / 3)            // сколько встречал
      + 0.10 * recencyFactor                       // насколько недавно (exp decay)
      - 0.10 * (corrections / max(usageCount,1))   // штраф за ошибки

status = when {
    score >= 0.85 && usageCount >= 10  → MASTERED
    score >= 0.55                       → PRODUCING
    score >= 0.30                       → LEARNING
    lessonSeen || score > 0            → SEEN
    else                                → UNKNOWN
}
```

## Что это даёт юзеру

1. **Конкретный прогресс** — "342 слова" лучше абстрактного XP
2. **Объективная CEFR-оценка** — на основе реального словаря
3. **Адаптивные подсказки** — "у тебя слабовато B1, давай тренировать"
4. **Дофамин** — каждое новое слово = достижение
5. **Drill-down лучшая практика**:
   - "Покажи 50 закреплённых" → видит достижения
   - "Слабые" → один тап → флэшкард-сессия из них
   - "Подзабыл" → SM-2 принудительно поднимает их в пул

## Точка входа

3 варианта:
1. ✅ **Рекомендуется: Profile → новая плитка "Мой словарь"** (логично,
   как "Эта неделя")
2. ❌ Stats screen — будет перегруз
3. ❌ Bottom Bar — слишком прямолинейно

+ Deep link с HomeScreen ("📚 342 слова") как мотивационный hook.

## Что НЕ делаем сейчас

- ML-модель CEFR-классификации слов (используем существующие маппинги)
- Per-collocation tracking (только bigram юзер-фраз — уже есть в
  UserWordFrequency v1.25.27)
- Cross-language word linking (рус→исп пары) — отдельная задача
- Социальные сравнения "ты знаешь больше N% юзеров" — нужны cohorts
