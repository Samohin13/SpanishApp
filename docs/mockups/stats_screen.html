Реализация (high‑level)

  • Новый route в Navigation.kt → stats. Открывать тапом на WeekHeatmap в HomeScreen.kt:308 и на WeeklyHeatmapTile в ProfileScreen.kt:527.
  • StatsViewModel — единый combine() Flow из dailyXpDao.observeAll(), userProgressDao, lessonProgressDao, flashcardSetProgressDao, libroProgressDao, gameLevelProgressDao, gameMistakeDao, wordDao, achievementDao, radioListeningDao. Фильтрация по выбранному Period.
  • Графики — Compose Canvas (bar/line/calendar). Без новых зависимостей. MPAndroidChart вытащит +600KB в AAB — не нужен.
  • Period state в DataStore (stats_preferences) — запомнить выбранный таб между сессиями.
  • Локализация — все строки в strings.xml/values-en/uk/es (контент уроков заморожен, UI — нет).
  • Шаринг (опционально, фаза 2) — рендер summary‑карточки в Bitmap через captureToBitmap, share intent.
  • Что нельзя посчитать сейчас: пер‑ответный accuracy уроков (нужен новый answer_log с миграцией). Сейчас аккуратно считаем «ошибки» только по game_mistakes, weak SM‑2 pool и avg bestPercent.
