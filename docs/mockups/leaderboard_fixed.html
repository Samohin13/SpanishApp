Как это решает 3 проблемы

  • Проблема 1 (Вьетнам без флага) → deviceCountryCodeAsync() теперь имеет 6-уровневый fallback: Override → Network ISO → SIM ISO → IP-API (country.is) → Locale → Cached. WiFi-only вьетнамец без SIM теперь корректно определится через IP. Плюс юзер может вручную выбрать через picker.
  • Проблема 2 (оба Estudiante) → optIn() теперь проверяет имя ДО синхронизации. Если displayName == "Estudiante", открывается обязательный диалог. В Firestore попадёт только реальное имя. Race condition устранён через suspend fun updateDisplayName().join() перед syncSelf().
  • Проблема 3 (противоречие ранга) → В LeaderboardRepository.fetch() добавлена вторичная сортировка compareByDescending { skillRating }.thenBy { updatedAt } в Kotlin (без composite Firestore index — экономим миграцию схемы). myRank = indexOfFirst { uid } + 1 — гарантированно согласован с визуальным порядком.
