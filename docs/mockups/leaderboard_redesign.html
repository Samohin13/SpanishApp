3 ключевые идеи редизайна

  1. Атмосфера на табе. Каждый таб — своё «настроение»:
    • Неделя — синий фон лиги Bilbao + 🏛️ watermark + countdown
    • Казахстан — зелёно-жёлтый градиент флага + крупный пьедестал с короной
    • Мир — глобус-watermark + live-ribbon + lederboard стран
  2. Пьедестал вместо трёх ровных карточек. Сейчас 🥇🥈🥉 — одинаковые рядом. Делаем настоящий 3D-эффект: золото выше всех, корона, цветные градиенты. Сразу видно кто первый.
  3. Мир — соревнование стран по умолчанию. Сейчас «Мир» = тот же список людей что Казахстан. Скучно. Делаем по умолчанию рейтинг СТРАН (Россия 671M XP, Испания 814M…), а индивидуальный список — через переключатель «👤 Игроки». Это даёт смысл: «моя страна #3 в мире — давай-ка вытащим её на #2».

Технически: ~250 строк Compose (3 hero-секции + новый PodiumStage + countries aggregator). Для countries-листа нужен Firestore aggregation — можно сделать через периодический Cloud Function или клиентский group-by из leaderboard collection (для начала достаточно).
