## Правила архива

1. **Не удаляем** — файлы остаются в git, можно вернуться через `git log --follow`
2. **Помечаем в этом README** что перенесено и почему
3. **Не редактируем** содержимое архива — это снимок «как было»
4. **При референсе к архивному файлу** — указывать дату архивации (для будущих агентов)
