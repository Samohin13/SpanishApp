## 🛠 Архитектура

### Главное решение: **генератор, а не ручное авторство**

Авторить 240 × 10 = 2400 упражнений вручную нереально. Делаем:

```
ExerciseGenerator(content, lessonTags, wordPool) → List<LessonExercise>
```

Генерит автоматически из существующих данных:
- Слова урока → ListenAndPick, ListenAndType, MatchPairs, OrderTheLetters
- Слова с артиклями → GenderArticleTap
- Глагольные уроки → ConjugationGrid (из таблицы `conjugations` в БД)
- Фразы для BuildSentence → парсятся **из текстов Libros** (100 готовых рассказов с известным CEFR-уровнем!)
- SpotTheError + идиомы → авторим / LLM-генерим в JSON

Существующие 2200 ручных упражнений = «seed», генератор добивает до 10 на урок.

### Время генерации: **runtime, на старте урока**, с seed = (lessonId, попытка)
- Один и тот же seed → одинаковые упражнения если юзер ошибся и переигрывает
- Новая попытка → свежие упражнения (replay value)

### Сложность по уровням (whitelist)
- **A1**: MC, ListenAndPick, MatchPairs, TapMissingWord, OrderLetters, ArticleTap, Speaking
- **A2**: + FillBlank, Translate(ru→es), ListenAndType, ConjugationGrid (1 ячейка), CategorySort, **BuildSentence**
- **B1**: + **BuildSentenceWithDistractors, ReorderWords**, SpotTheError, ConjugationGrid (полный), Translate (es→ru)
- **B2**: всё + **DragToFillBlanks**

## ❓ 5 решений до старта

### 1. Качество авто-Translate
Для одного слова («casa → дом») надёжно, для фраз — могут быть ошибки/неоднозначности.
- **A**: ограничить генератор только словами, фразы — только авторские (медленнее, но точно)
- **B**: разрешить фразы, принять ~5% спорных (быстрее)

### 2. SpotTheError — источник 300 ошибочных вариантов
- **A**: LLM-проход (Gemini), ты ревьюишь батчем — 1 день работы тебе
- **B**: вручную пишем — медленно, но контроль 100%

### 3. ConjugationGrid vs игра Verbos (дублирование)
- **A**: в уроке только single-cell quick-check (1 пропуск в таблице) — мало пересечения с игрой
- **B**: полная таблица из 6 ячеек — параллель с игрой, но насыщеннее урок

### 4. Sealed-class рефакторинг
- **A**: оставить compat-shim навсегда (старые `Exercise(type=…)` вызовы продолжают работать)
- **B**: одним PR переписать все 2200 на новый формат (чище код, но риск опечаток)

### 5. Runtime-генерация и пустая БД на первом запуске
- **A**: блокировать вход в урок до окончания seed
- **B**: разрешить, первые секунды дистракторы будут слабее
