## 📅 6 фаз раскатки

### Phase 0 — Content Delivery System (1 неделя, M) ⭐ СНАЧАЛА
**Зачем:** скачивать контент с сервера, а не паковать в APK. Это даёт:
- Размер APK падает на ~20 МБ
- Контент обновляется без релиза в Play Store
- Юзер видит профессиональный first-launch (как у крупных приложений)

**Что делаем:**
1. **Firebase Storage bucket** + manifest.json
2. Разделение текущего контента на версионированные пакеты:
   - `core_v1.json` — базовый словарь (200 КБ)
   - `lessons_a1_v1.json` … `lessons_b2_v1.json` — уроки по уровням
   - `libros_a1_v1.json` … `libros_b2_v1.json` — рассказы
   - `images_v1.zip` — картинки слов (1.6 МБ)
3. **ContentDownloader** Kotlin-сервис:
   - OkHttp с progress callback
   - Подсчёт скорости (МБ/с) live
   - Retry при сбое сети
   - Параллельное качание нескольких пакетов
   - Распаковка zip + парсинг JSON
   - Запись в Room
4. **DownloadScreen** — экран первого запуска:
```
┌─────────────────────────────────────┐
│  ESPEAK                             │
│                                     │
│  📦 Загрузка пакетов упражнений     │
│                                     │
│  ▰▰▰▰▰▰▰▰▰▱▱▱▱▱  64 %               │
│                                     │
│  Загружено: 3.2 МБ из 5.1 МБ        │
│  Скорость:  1.4 МБ/с                │
│                                     │
│  • Базовый словарь   ✓              │
│  • Уроки A1          ✓              │
│  • Уроки A2          скачивается… │
│  • Картинки          ожидание       │
└─────────────────────────────────────┘
```
5. **UpdateChecker** — на каждом запуске проверяет manifest, тихо качает изменения в фоне

**Файлы:**
- `service/ContentDownloader.kt` (новый)
- `service/ContentManifest.kt` (новый)
- `ui/onboarding/DownloadScreen.kt` (новый)
- `data/db/seeders/PackSeeder.kt` (рефакторинг текущего seeder)
- Удаление контента из `BasicsVocab.kt`, `LibrosData.kt`, `LessonContentData.kt`

**Юзер видит:** при первом запуске — экран загрузки с прогрессом и скоростью. После — полноценное приложение. На обновлениях — тихая фоновая синхронизация.
