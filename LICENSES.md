# Лицензии открытого ПО — ESPEAK

ESPEAK использует следующие open-source библиотеки и ассеты. Спасибо их авторам.

## Android & Jetpack

- **Android Jetpack** (Compose, Navigation, Hilt, Room, DataStore, WorkManager, Glance) — Apache License 2.0
- **Material Components for Android** — Apache License 2.0
- **Kotlin** — Apache License 2.0
- **Kotlin Coroutines / kotlinx.serialization** — Apache License 2.0

## Сетевые / форматы

- **OkHttp** (Square) — Apache License 2.0
- **Coil** (image loading) — Apache License 2.0

## Анимации

- **Lottie for Android** (Airbnb) — Apache License 2.0
- Lottie JSON-анимации в `res/raw/` загружены с [lottiefiles.com](https://lottiefiles.com) на Free-условиях.

## Firebase

- **Firebase BOM** (Auth, Firestore, Storage, Crashlytics, Analytics) — Apache License 2.0

## Иконки

- **Material Symbols / Material Icons** — Apache License 2.0
- **Bull silhouette icon** (`drawable/ic_bull.xml`, foreground в `ic_launcher_foreground.xml`) — `game-icons:taurus` от Lorc, лицензия [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) (через [iconify.design](https://iconify.design))

## Изображения

- **Google Material Symbols** — Apache License 2.0
- Иконки категорий — Material Icons (Apache 2.0)
