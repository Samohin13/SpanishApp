TL;DR. ESPEAK — образовательное приложение для изучения испанского. Мы не продаём данные, не показываем рекламу, не отслеживаем местоположение. Аудио с микрофона никогда не сохраняется и не покидает устройство в виде записи. Все сетевые запросы идут по HTTPS. Удаление аккаунта — по запросу через email или из настроек.

1.2. Данные, которые собираются автоматически

  • Прогресс обучения — выученные слова, пройденные уроки, ответы в играх, серия дней, опыт (XP), Skill Rating. Хранятся локально в БД Room и (если вы вошли в аккаунт) синхронизируются в Firestore.
  • Записи голоса не сохраняются — микрофон используется ТОЛЬКО для распознавания речи в упражнениях произношения через системный Android SpeechRecognizer. Аудио-буфер обрабатывается в реальном времени, никогда не записывается в файл и никогда не передаётся на наши серверы или серверы Google как файл.
  • Сообщения ИИ-чата — текст ваших сообщений к ИИ-репетитору отправляется через наш прокси (Cloudflare Worker) на серверы Google Gemini. Сами серверы Google НЕ сохраняют ваши сообщения для обучения моделей (см. условия Gemini API). Локально история чатов хранится в БД Room на вашем устройстве — можно очистить в любой момент.
  • Crashlytics (Firebase) — анонимные стек-трейсы при крашах для исправления багов. Никаких персональных данных в крашах нет.
  • Analytics (Firebase) — обезличенная статистика использования экранов и событий (например, «прошёл урок A1-3», «зашёл в Libros»). Помогает решать, какие функции улучшать.

  • ❌ Уникальные идентификаторы устройства (IMEI, MAC, advertising ID)

  • ❌ Записи микрофона как файлы

2. Как мы используем данные

  • Функциональность приложения — отображение прогресса, подбор слов для повторения, расчёт рейтинга и серии дней.
  • Персонализация — выбор уроков по вашему уровню, адаптивный подбор слов для тренировки слабых мест.
  • Социальные функции — отображение в лидерборде и недельных лигах (только при вашем опт-ине, можно отключить).
  • Облачная синхронизация — если вы зарегистрированы, прогресс сохраняется в облаке и доступен с другого устройства.
  • Аналитика — обезличенное понимание, какие функции популярны, какие нет — для приоритизации улучшений.
  • Отчёты о крашах — стабилизация приложения, исправление багов.
  • Связь с разработчиком — ответ на ваши обращения по email.

Мы НЕ продаём ваши данные третьим лицам. Мы НЕ показываем рекламу. Мы НЕ передаём данные брокерам данных.

3. Передача данных третьим лицам

3.1. Сервисы Google / Firebase

  • Firebase Authentication — авторизация (email/пароль и Google Sign-In).
  • Firebase Firestore — лидерборд, лиги, облачный прогресс.
  • Firebase Storage — аватары.
  • Firebase Cloud Messaging — не используется в текущей версии; зарезервировано на будущее (push-уведомления).
  • Firebase Crashlytics — отчёты о крашах.
  • Firebase Analytics — обезличенная аналитика.
  • Google Play Services — Google Sign-In, in-app billing (для будущих подписок).

Обработка данных Google регулируется Политикой конфиденциальности Google и политикой Firebase.

3.2. Google AI (Gemini)

При использовании ИИ-репетитора (чата в приложении):

  • Ваше текстовое сообщение → отправляется через наш Cloudflare Worker (прокси, не сохраняет содержимое) → серверы Google Gemini → ответ возвращается в приложение.
  • Согласно условиям Gemini API, Google НЕ использует ваши запросы для обучения моделей (PAYG-режим).
  • Локально в БД Room сохраняется история ваших чатов — для отображения предыдущих сообщений. Можно удалить вручную.

3.3. Cloudflare

Мы используем Cloudflare Workers (espeak-gemini-proxy.bravochief21.workers.dev) как прокси к Gemini API. Это нужно, чтобы наш API-ключ Gemini не попадал в декомпиляцию APK. Cloudflare видит зашифрованный HTTPS-трафик, но не его содержимое; логи запросов не хранятся.

4. Разрешения приложения

ESPEAK запрашивает следующие Android-разрешения:

PermissionТипЗачем
INTERNET Normal Сетевые запросы к Firebase, Cloudflare Worker и Gemini API. Без интернета приложение работает оффлайн, кроме ИИ-чата и лидерборда.
ACCESS_NETWORK_STATE Normal Проверка типа подключения (Wi-Fi/мобильный), чтобы аккуратно использовать трафик при синхронизации.
RECORD_AUDIO Dangerous (запрашивается во время использования) Распознавание речи в упражнениях произношения через системный Android SpeechRecognizer. Аудио НЕ записывается в файл и НЕ передаётся на серверы. Микрофон активируется только в момент нажатия кнопки «Говорить» и автоматически отключается после произнесения фразы.
POST_NOTIFICATIONS Dangerous (Android 13+) Локальные уведомления-напоминания заниматься (раз в день, время задаёте вы). Можно отключить в настройках приложения или в системных настройках.
VIBRATE Normal Тактильная отдача при ответах в карточках и играх (можно отключить).

Биометрия (отпечаток/Face Unlock) используется только если вы включили блокировку приложения биометрией в настройках. Биометрические данные обрабатывает сама Android-система, нам они никогда не передаются.

5. Фоновая работа (WorkManager)

Приложение использует Android WorkManager для нескольких периодических задач — все они работают локально на устройстве:

  • DailyReminderWorker — раз в день в выбранное вами время отправляет локальное уведомление с напоминанием позаниматься.
  • RatingDecayWorker — раз в день пересчитывает skillRating с учётом затухания за неактивность.
  • WeeklyLeagueService — раз в неделю обновляет состояние недельной лиги (только если вы её включили).

Никакая фоновая задача не отправляет ваши данные третьим лицам без вашего опт-ина в соответствующую функцию.

6. Хранение и удаление данных

6.1. Локальные данные

Хранятся в БД Room на устройстве, в песочнице приложения. Удаляются автоматически при удалении приложения. Также можно сбросить локально через Настройки → Дополнительно → Сбросить прогресс.

6.2. Облачные данные

Хранятся в Firebase. Чтобы удалить:

  • Через приложение: Настройки → Управление аккаунтом → Удалить аккаунт. Удаляет ваш Firebase Auth-аккаунт и все связанные данные в Firestore/Storage.
  • По email: напишите на es.espeak13@gmail.com с темой «Удалить мой аккаунт ESPEAK». Удаление в течение 30 дней.

6.3. Сроки хранения

  • Активные аккаунты — пока вы пользуетесь приложением.
  • Неактивные аккаунты (не входили 2+ года) — удаляются автоматически при ближайшей чистке.
  • Логи Crashlytics — 90 дней.
  • Данные Analytics — 14 месяцев (стандарт Firebase).

7. Безопасность

  • Все сетевые запросы используют HTTPS/TLS.
  • Пароли никогда не хранятся в открытом виде — Firebase хеширует их с использованием bcrypt.
  • API-ключ Gemini не находится в APK — все запросы к Gemini идут через наш Cloudflare-прокси, защищённый Firebase ID Token и shared secret.
  • Локальная БД защищается стандартными механизмами Android (sandbox, internal storage).
  • Виджет «Слово дня» защищён permission BIND_APPWIDGET — другие приложения не могут взаимодействовать с ним.
  • Firestore Security Rules ограничивают доступ к данным: пользователь может читать/писать только свои документы; только аутентифицированные пользователи имеют доступ к лидерборду.
